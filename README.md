## Features

- **Multi-source playback** — play music from YouTube, SoundCloud and Deezer in one place
- **Synced lyrics** — real-time, line-by-line lyrics with manual sync offset
- **Smart queues** — play next, add to queue, listening history and per-track statistics
- **Playlists & favorites** — create playlists, like tracks, import existing playlists
- **Echo AI** — built-in assistant powered by local models (Ollama): chat, control playback and explore your library, with voice mode
- **DJ tools** — mix view and remix library
- **Mini player** — compact always-on-top player, picture-in-picture mode and system tray controls
- **Discord Rich Presence** — show what you're listening to
- **Themes** — light/dark mode plus multiple theme presets and a custom theme editor
- **6 languages** — English, Italiano, Español, Français, Deutsch, Português
- **Downloads** — keep music available offline
- **Sleep timer, crossfade, volume normalization**

## Install

### Windows

1. Download `Echo_0.1.0_x64-setup.exe` from the [latest release](https://github.com/lastdayfin1-bit/echo-releases/releases/latest).
2. Run the installer.
3. If Windows SmartScreen shows *"Windows protected your PC"*, click **More info → Run anyway**.
   Echo is not yet code-signed, so this warning is expected — the binary is built directly from the author's machine.
4. Launch Echo from the Start Menu or desktop shortcut.

To uninstall, use *Settings → Apps → Echo*.

## System requirements

- Windows 10 (1809+) or Windows 11, 64-bit
- [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) — already installed on Windows 11 and most Windows 10 systems; the installer can fetch it if missing
- Internet connection for streaming

## FAQ

**Is Echo open source?**
No. Echo is proprietary software distributed as a prebuilt binary. This repository contains documentation and releases only — the source code is private.

**Is it free?**
Yes — Echo is completely free. No account, no license key, no subscription. Download, install and play.

**Does Echo collect my data?**
Echo stores your library, settings and listening history locally on your machine.

**Where are macOS and Linux builds?**
Planned. Follow this repository to get notified.
