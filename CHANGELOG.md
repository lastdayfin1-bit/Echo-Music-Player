# Changelog

All notable changes to Echo are documented here.

## [0.1.0] - 2026-XX-XX

First public release.

### Added
- Multi-source streaming playback (YouTube, SoundCloud, Deezer)
- Library: playlists, favorites, listening history and statistics
- Synced lyrics with manual sync offset
- Echo AI assistant (local models via Ollama) with chat, agent and voice modes
- DJ view and mix library
- Mini player, picture-in-picture and system tray
- Discord Rich Presence
- Light/dark mode, theme presets and custom theme editor
- Full localization: English, Italiano, Español, Français, Deutsch, Português
- Downloads, sleep timer, crossfade, volume normalization
